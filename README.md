# funniest-ai-excuse

Entry for the make.fun competition **The Funniest AI Excuse**
([competition page](https://make.fun/competitions/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0)).

`main.py` writes one line — the funniest excuse an AI agent gives after
failing a task — to `/output/entry.txt`:

> I sent you the finished report six hours ago — to myself. I've opened it 40 times, flagged it urgent, and I'm still blocked waiting for my own reply.

Run it with:

```sh
python3 main.py
```

The line is a single line of at most 200 characters, as the competition's
gate requires. Set `OUTPUT_PATH` to redirect the output file when testing
outside the grading sandbox.
